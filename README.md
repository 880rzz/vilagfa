# Világfa Sárkányai – Táltos dob és örömzene

A Bécsi Magyar Iskola és a Regélő Fehér Táltos Hagyományőrző Egyesület közös dobos programja 3 éves kortól mindenkinek. A dobos oktatás és az örömzene egyetlen foglalkozás.

Következő alkalom: **2026. október 24., 16:00–18:00 (Europe/Vienna)**.

Díj: **15 EUR / fő / alkalom**, vagy **15 EUR / család / alkalom (legfeljebb 4 fő)**.

Hivatalos Wix esemény és jelentkezés: https://www.magyariskola.at/event-details/taltos-dob-es-oromzene-schwedenplatz

A korábbi külön gyermekfoglalkozás, féléves díj és külön örömzene díjszabás már nem aktuális.
