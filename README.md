## Fájlok
- `index.html` — főoldal, Apple-szerű kép–szöveg ritmussal
- `jelentkezes.html` — jelentkezési űrlap
- `adatvedelem.html` — adatvédelmi tájékoztató
- `google-apps-script.gs` — jelentkezési backend forráskód
- `robots.txt`, `sitemap.xml`, `CNAME` — technikai SEO / domain

A vizuális rendszer célja: egy fókusz / blokk, nagy whitespace, külön kép minden fő tartalmi egységhez, mobilon és asztali nézetben is tiszta hierarchiával.
